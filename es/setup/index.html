Bobathon Readiness Checklist

Before entering the Dojo, make sure every item below is in place:

  • Bob IDE installed and running — workspace open and operational.
  • Bob PPZ extension installed — Premium Package for Z and its dependencies enabled (trial access active).
  • Facilitator materials received — challenge material, sample repositories, and event instructions.
  • Kata workspace open — unzip the kata package and open bobathon-z-dojo-katas in Bob IDE; kata-01, kata-02, … must appear at the root of the Explorer.

Quick Verification

  1. Test Bob Chat Panel: Open the Bob side panel (Ctrl + Alt + B / Cmd + Option + B or click the Bob icon in the activity bar) and run:

    Expected result: Bob responds immediately, listing available modes (Ask, Plan, Agent, Z-Code, Z-Architect).

  2. Verify Z Language Highlighting: Open any .cbl, .pli, or .jcl sample file from your facilitator kit. Expected result: The editor recognizes the language and syntax highlighting is fully active.

  3. Check Context Hygiene: Close unneeded files and terminal tabs so your context window is dedicated exclusively to the exercise.

No live mainframe required for Floor 01!

All Floor 01 kata run entirely on local sources in your editor. You do not need active z/OS VPN credentials or remote LPAR connections to complete these fundamental exercises.
